#### 교재 : 자바의 정석 (4판)
##### 저자가 추천하는 공부 방식

이 책은 크게 1  1장 ~ 5장, 6장 ~ 9장, 그 외 이렇게 3부분으로 나눠진다고 함.

2장 ~ 5장 → 처음 배우는 사람 (익숙해질때까지 반복)  
6장 ~ 7장 → 객체지향 핵심 ( 6장을 가볍게 훑고, 여러번 반복 7장은 유튜브를 통해서 확인하면 도움이 됨)  
2장 ~ 9장 → 자바의 기본적인 내용이므로 반복  
10장 ~ → 자바의 응용 버전, 앞에 내용이 숙지가 안되면 이해하기가 어려움

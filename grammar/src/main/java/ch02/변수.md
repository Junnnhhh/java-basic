## 변수
#### 변수 → 단 하나의 값을 저정할 수 있는 메모리 공간

#### 변수 선언 방법
```java
int age; // int : 변수타입, age : 변수 이름

int x, y; // 변수 타입이 같은 변수를 여러개 선언 가능
```

#### 변수 초기화
```java
int age = 25; // 변수 age를 선언하고 25로 초기화
```

> 변수의 초기화란, 변수를 사용하기 전에 처음으로 값을 저장하는 것

#### 변수의 명명규칙
> 변수의 이름처럼 프로그래밍에서 사용하는 모든 이름을 `식별자` 라고 함<br>식별자를 만들 떄 아래 규칙을 지켜야 한다.  
>> 1. 대소문자가 구분되며 길이에 제한이 없다. <br>- True와 true는 서로 다른 것으로 간주
>> 2. 예약어를 사용해서는 안 된다. <br>- true는 예약어라서 사용할 수 없지만, True는 가능하다.
>> 3. 숫자로 시작해서는 안 된다. <br>- top10은 허용하지만, 7up은 허용되지 않는다.
>> 4. 특수문는 '_'와 '$'만을 허용한다. <br> - \$harp은 허용되지만, S\#arp은 허용되지 않는다.
>> 
> 예약어(reserved keyword) → 프로그래밍언어의 구문에 사용되는 단어

#### 자바 프로그래머들에게 권장하는 변수 명명규칙
> 1. 클래스 이름의 첫 글자는 항상 대문자로 한다.<br> - 변수와 메서드의 이름의 첫 글자는 항상 소문자로 한다.
> 2. 여러 단어로 이루어진 이름은 단어의 첫 글자를 대문자로 한다.<br> - lastIndexOf, StringBuffer
> 3. 상수의 이름은 모두 대문자로 한다. 여러 단어로 이루어진 경우 '_'로 구분한다.

## 산술 연산자

---
> 이 개념은 누구나 다 아는거라 주의할 점만 나열해본다.

```java
long a = 1_000_000 * 1_000_000;
```

이 식에서 a 값에 어떤 값이 저장될 것 같나? <br>
이 식에서는 원하는 값을 못 얻는다. <br><br>

이미 int 타입의 계산이 이뤄지는데, 이 연산의 결과값은 int 범위를 넘어서 오버플로우가 발생한다.<br>
이미 오버플로우가 난 값을 long으로 형변환해도 소용이 없다. <br>

따라서 원하는 값을 가지고 싶다면 피연산자 둘 중에 하나를 long으로 형변환 해야한다.

---
### 나머지 연산자
> 나머지 연산자(%)는 나누는 수로 음수도 허용한다. 그러나 부호는 무시되므로 결과는 음수의 절대값으로 나눈 나머지와 결과가 같다. <br>
 ```java
System.out.println(10%8); // 2
System.out.println(10%-8); // 2
```
> 그냥 피연산자의 부호를 모두 무시하고, 나머지 연산을 한 결과에 왼쪽 피연산자(나눠지는 수)의 부호를 붙이면 된다.

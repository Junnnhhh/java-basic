
## 변수의 타입
우리가 사용하는 데이터 타입은 크게 문자, 숫자로 나눌 수 있으며, 숫자는 정수와 실수로 나눌 수 있다.

### 기본형과 참조형
기본형 변수 → 실제 값을 저장
- 논리형(boolean), 문자형(char), 정수형(byte, short, int, long), 실후여(float, double)
  <br> 계산을 위한 실제 값을 저장한다. 모두 8개
> boolean, byte → 1byte <br> char, short → 2byte <br>
> int, float → 4byte <br> long, double → 8byte

참조형 변수 → 어떤 값이 저장되어 있는 주소를 값으로 가짐
- 객체의 주소를 저장한다. 8개의 기본형을 제외한 나머지 타입
> 클래스이름 변수이름; // 변수의 타입이 기본형이 아닌 것들은 모두 참조변수

### 상수와 리터럴
#### 상수
- 값을 저장할 수 있는 공간이지만 한번 값을 저장하면 다른 값을 변경할 수 없음.
<br> 변수의 타입 앞에 키워드 `final`을 붙이면 된다.
```java
final int MAX_SPEED = 10; // 상수 MAX_SPEED를 선언 & 초기화
```
```java
final int MAX_VALUE; // 상수 MAX_VALUE를 선언
MAX_VALUE = 100; // 상수 MAX_VALUE를 초기화
MAX_VALue = 200; // 에러. 상수의 값은 변경할 수 없음

```

#### 리터럴
- 그 자체로 값을 의미하는 것
```java
int year = 2014;
final int MAX_VALUE = 100;

// 여기서 2014, 200 이 리터럴
```
> 리터럴의 타입과 접미사
> <br> long 타입은 접미사 L
> <br> 실수형의 경우, 접미사 f, d `실수형에서는 double이 기본 자료형`
>> 리터럴에 접미사가 붙는 타입은 long, float, double 뿐인데, <br>
>> douvle은 생략가능하므로 long과 float의 리터럴에 접미사를 붙이는 것만 신경쓰자.

#### 타입의 불일치
> 타입이 달라도 저장범위가 넓은 타입에 좁은 타입의 값을 저장하는 것은 허용된다.
```java
int i = 'A'; // 문자 'A'의 유니코드인 65가 변수 i에 저장
long l = 123; // int보다 long이 더 범위가 넓다
double d = 3.14f; // float보다 double이 더 범위가 넓다.

int i = 0x123456789; // ERROR int의 범위를 넘는 값을 저장
float f = 3.14; // ERROR. float보다 double의 범위가 넓다.
```

#### 지역 변수의 타입 추론 - var
> var 변수는 값의 타입을 보고 변수의 타입을 추론할 수 있게 하는 변수
```java
var year = 2024;
int year = 2024;
// 두 개 모두 동일 코드
```
만일 var 변수를 선언할 때, 초기화하지 않거나 null을 대입하면, 변수의 타입을 <br>
추론할 수 없기 때문에 오류가 발생한다.
<br> 또한, 아래의 경우에도 의도했던 것과 다르게 타입이 추론될 수 있으므로 주의
```java
byte b = 123; // byte 변수
var b = 123; // 정수형의 경우 기본형이 int이기 때문에 int로 추론
```

#### 문자 리터럴과 문자열 리터럴
'A'와 같이 작은 따옴표로 문자 하나를 감싼 것을 '문자 리터럴'이라고 한다,<br>
두 문자 이상은 큰 따옴표로 감싸야 하며 '문자열 리터럴'이라고 한다.<br>

문자열 리터럴은 "" 안에 아무런 문자도 넣지 않는 것을 호용하지만, <br>
문자 리터럴은 반드시 '' 안에 하나의 문자가 있어야 한다.
> 문자열 + any type → 문자열 + 문자열 → 문자열<br>
> any type + 문자열 → 문자열 + 문자열 → 문자열

#### 텍스트 블럭(text blocks)
이 기능은 여러 줄로 이루어진 문자열을 작성하기 편리하게 도와준다.
```java
String str = """
        class Main {
            public String main(String args[]) {
                System.out.println("Hello");
            }
        }
        """;
```
> 텍스트 블럭의 시작과 끝을 의미하는 """ 사이에 텍스트를 탭 문자가 개행문자 없이<br>
> 자유롭게 작성하면된다. 주의할 점은 아래와 같이 여는 """의 다음 줄 부터 내용이 시작해야 한다.
```java
String str1 = """Hello"""; // ERROR 텍스트 블럭의 시작 """ 뒤에 내용이 오면 안됨
String str2 = """
        Hello        
        """; // "Hello"와 동일
```
그리고 닫는 """의 위치에 의해 들여쓰기의 기준이 된다는걸 알아야 한다.
```java
String str3 = """
        Hello
        """; // "Hello\n"와 동일

String str4 = """
            Hello
        """; // "    Hello\n와 동일. 닫는 """의 위치가 들여쓰기의 기준

```

#### 형식화된 출력 - printf()
printf()는 '지시자'를 통해 변수의 값을 여러 가지 형식으로 변환하여 출력하는 기능이 있다.<br>
'지시자'는 값을 어떻게 출력할 것인지를 지정해주는 역할을 한다.

자주 사용하는 지시자
- %b : boolean 형식으로 출력
- %d : 10진 정수의 형식으로 출력
- %o : 8진 정수의 형식으로 출력
- %x, %X : 16진 정수의 형식으로 출력
- %f : 부동 소수점의 형식으로 출력
- %e, %E 지수 표현식의 형식으로 출력
- %c : 문자로 출력
- %s : 문자열로 출력
- %n : 줄바꿈

조금 더 알아두면 좋은 예제
> %5d : 총 글자 수가 5가 되게 앞에 공백 추가 
> <br> %-5d : 총 글자 수가 5가 되게 뒤에 공백 추가
> <br> %05d : 총 글자 수가 5가 되게 앞에 0 추가
> <br> 실수형의 경우, %전체자리.소수점아래자리f
> <br><br>
> 지시자 '%x'와 '%o'에 '#'을 사용하면 접두사 '0x'와 '0'이 각각 붙는다. <br>
> 그리고 '%X'는 16진수에 사용되는 접두사와 영문자를 대문자로 출력한다. <br><br>
> 10진수를 2진수로 출력해주는 지시자는 없기 때문에 정수를 2진 문자열로 변환해주는<br>
> Interger.toBinaryStrgin(int i)를 사용하고 지시자를 %s를 써주면 된다. <br><br>
> 자바에서는 char 타입의 값을 %d 지시자를 통해서 출력하고 싶은 경우, int형으로 형변환을 꼭 해줘야 함.

### 대입 연산자 = op =
> 대입 연산자는 변수와 같은 저장공간에 값 또는 수식의 연산결과를 저장하는데 사용 <br>
> 대입 연산자의 왼쪽 피연산자를 **lvalue**, 오른쪽 피연산자를 **rvalue**라고 함. <br><br>
>
> 대입연산자의 rvalue는 변수뿐만 아니라 식이나 상수 등이 모두 가능하지만, <br>
> lvalue의 경우 반드시 변수처럼 값을 변경할 수 있는 것이어야 함.

#### 복합 대입 연산자
> ex) i = i +3 → i += 3 이렇게 표현할 수 있음

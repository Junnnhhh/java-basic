## 비교 연산자

---
### 실수형 비교 시, 주의사항
```java
boolean a = 0.1 == 0.1f;
```
> 여기서 a의 값은 true일까?<br>
> **아니다.** 답은 **false** 이다.

> ❓ 정수형과 달리 실수형은 근사값으로 저장되므로 오차가 발생할 수 있기 때문이다.<br><br>
> ex) 10.0f의 경우 오차없이 저장할 수 있는 값이라서 double로 형변환해도 그대로 10.0이 되지만,<br>
> 0.1f는 저장할 때 2진수로 변환하는 과정에서 오차가 발생한다. <br>
> double 타입의 상수인 0.1도 저장되는 과정에서 오차가 발생하지만, float 타입의 리터럴인 0.1f보다 적은 오차로 저장된다.

```java
float f = 0.1f; // f에 0.10000000149011612 로 저장된다.
double d = 0.1; // d에 0.10000000000000001 로 저장된다.
```
